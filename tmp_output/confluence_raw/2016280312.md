1.DoIP -> DoCAN
===============

1.1 Requriement
===============

* 24CY의 차량 네트워크가 Ethernet에서 CAN으로 변경됨에 따라 현 DoIP 대신 DoCAN을 처리해야함
* 24LC 공통 사양

1.2 SW Architecture Design
--------------------------

* 2안으로 결정
  + 추가 결정 사항: 세션콘트롤기능의 경우 DCM Core의 승인을 받아되는데 VectorSIP가 이런 구조가 아니어서 고객사와 논의 후 DCM Core의 승인을 받지 않기로 설계 변경 합의
* Architecture#2 has been selected. but AED does not fall out and plays a role in delivering OTA DoIP and UDS to DiagMgr

|  | 1안) AED가 DoIP 뿐 아니라 DoCAN을 UDS로 변경하는 역할도 수행하게 함 | 2안) MCU에서 DoCAN을 UDS로 변경시킴 |
| --- | --- | --- |
| Pros | * DoCAN / DoIP의 UDS(Unified Diagnostic Services protocol) AP의 DiagMgr+AED 조합에서 모두 일관성있게 처리 | * 부팅 초기 AP가 준비되지 않은 상황에서 빠른 DoCAN 메시지 처리 가능 (예, NRC 처리) |
| Cons | * AED에 UDS Session Control 기능 추가 구현 필요 | * MCU에서 Autosar(VectorSIP) 활용해 구현시 DoCAN UDS변경은 문제없으나 Session Control기능 구현시 DCM Core의 승인을 받아야되는 설계 변경필요 |
