## Problem Summary
This topic presents the architecture of the BT Manager component for BLE communication in the BMW ICON environment. The design covers discovery, advertising, connection setup, and GATT handling needed for communication with external devices.

Unlike many other topics, the material mainly presents one architecture rather than a comparison of multiple redesign alternatives. The emphasis is on how the Bluetooth Manager is organized functionally.
