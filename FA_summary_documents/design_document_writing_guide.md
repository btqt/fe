# Design Document Writing Guide

## Refer to the following content and guide at the mentor's discretion. The key points to emphasize are

- What problem is being addressed?
- Is the problem being approached in a structured manner?
- Have multiple alternatives been proposed and compared?
- Are the decisions made logical?

## Ensure these aspects are clearly presented

**1. Project Context**

- Project Overview and Background Explanation

**2. Problem what you want to solve**

- Detailed Description of the Problem to be Solved
- Functional Requirements and Quality Attributes etc
- System Context Diagram

**3. Architecture Alternatives to solve the problem**

- Propose Two or More Architectures to Solve the Problem

**4. Architecture diagrams which describe each alternative (Various perspectives)**

- Explanation of Each Proposed Architecture with Diagrams (Mix of Static View Dynamic View, etc.)
- UML or Informal (with Legend)

**5. Comparison between the alternatives**

- Comparison of Each Proposal (Pros and Cons, and Whether Quality Attributes are Satisfied)

**6. Architectural decision and rationale**

- Architectural decision and Rationale

**7. how to verify the final architecture design**

- Proof that the Chosen Architecture Truly Solves the Problem

**8. Conclusion**

- Conclusion, Reflections, Areas for Improvement, Future Plans, etc.
